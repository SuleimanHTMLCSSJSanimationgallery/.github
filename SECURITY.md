## Reporting a Vulnerability

We take the security of **SuleimanHTMLCSSJSanimationgallery** projects seriously.

If you believe you have discovered a vulnerability or security flaw in any repository under this organization:

1. **Do not** file a public issue on GitHub.
2. Email details of the vulnerability directly to **suleyman.hacizade1@gmail.com** with the subject line:
   `[SECURITY] SuleimanHTMLCSSJSanimationgallery Vulnerability Report`.
3. Provide step-by-step instructions or proof-of-concept code so our maintainers can reproduce and remediate the issue promptly.

We commit to acknowledging your disclosure within 48 hours and providing a coordinated patch release timeline.
